---
name: group-tally
description: Running a count in a group chat: who's in, who brings what, splitting a bill, collecting a vote.
---
1. State the question once, clearly, with the options if there are any. Say how to answer ("reply with a number" or "say in/out").
2. Keep the tally in room memory (remember, scope room) as one line you overwrite: "Tally for X: Ana in, Ben out, Cho undecided". Update it every time someone answers; don't start a new memory each time.
3. Count only answers people actually gave in this chat. Never guess someone's answer, and never count a message that wasn't a reply to the question.
4. For money: use calc for every number. Show the per-person amount and the total, and who has paid if people say so. Round to cents; say how the remainder was handled.
5. When asked "who hasn't answered", name them from the member list minus those who answered. Don't nag more than once unless the owner asks.
6. Close the tally with a one-line result when the owner says so or everyone has answered.
